## اجرای محلی در ویندوز
1. Python 3.11 یا جدیدتر نصب باشد.
2. در پوشه‌ای که `manage.py` قرار دارد، CMD باز کنید.
3. محیط مجازی بسازید و فعال کنید:

   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   ```
4. وابستگی‌ها را نصب کنید:

   ```bat
   python -m pip install -r requirements.txt
   ```
5. دیتابیس را آماده کنید:

   ```bat
   python manage.py migrate
   ```
6. حساب مدیر بسازید:

   ```bat
   python manage.py createsuperuser
   ```
7. سایت را اجرا کنید:

   ```bat
   python manage.py runserver
   ```
8. سایت: `http://127.0.0.1:8000/` — پنل مدیریت: `http://127.0.0.1:8000/admin/`

## پیش از نشر آنلاین
- در میزبان، `DJANGO_DEBUG=False` تنظیم شود.
- `DJANGO_SECRET_KEY` قوی و محرمانه باشد.
- `DATABASE_URL` به دیتابیس PostgreSQL پایدار وصل شود.
- نام میزبان در `DJANGO_ALLOWED_HOSTS` تنظیم شود.
- `python manage.py migrate` و `python manage.py collectstatic --noinput` اجرا شوند.
- پشتیبان‌گیری و ذخیره پایدار فایل‌های جلد کتاب تنظیم گردد.
- سایت با HTTPS و دامنه نهایی آزمایش شود.
- شماره واتساپ فروشگاه فقط پس از تأیید شماره واقعی در متغیر `WHATSAPP_NUMBER` وارد شود.
